Convert, then query

Plain Markdown on stdout, ready to pipe into mq. Slice a manual into sections, filter tables, or feed an LLM only what fits.

# Pull one section out of a Word doc
mq-conv document.docx | mq -A 'section::section("Summary")'

# Sections small enough to paste into a prompt
mq-conv manual.pdf -q '.h2 | select(tokens(.) < 500)'

# Only some pages, numbers stay those of the source
mq-conv report.pdf --pages 3-5

Features

Structure from the file itself, not a text dump and not a cloud parser.

Layout-aware PDF

Native glyph parser: columns, headings, lists, ruled and borderless tables, CJK fonts. Running headers and footers removed.

Local & offline

No API keys, no network, no Python or Node runtime. A single static binary.

Parallel

PDF pages and input files convert on all cores. A broken page never takes the document down.

Token budgeting

--max-tokens and --cursor page through large documents at block boundaries.

Built-in queries

-q runs an mq query with tokens(), format() and filename().

Page selection

--pages picks PDF pages, slides, sheets or EPUB chapters.

Images & OCR

--extract-images writes embedded images and links them; Tesseract OCR for scans.

Markdown out

--to writes docx, HTML, LaTeX, RST, AsciiDoc, Org, EPUB and JSON.

Modular & WebAssembly

Enable only the formats you need with feature flags; core formats also run in the browser.
